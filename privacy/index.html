Privacy, without fine print.

Meeple Import Doctor is designed to work without an account, analytics, cookies, advertising, or a server-side history.

What stays on your device

The last five inspected URLs and their diagnosis labels are stored in your browser’s local storage. Pasted page HTML is held in memory only while the page is open; it is not saved in history. You can clear recent inspections from the home page, and the action can be undone for seven seconds.

Requests to source websites

When you inspect a URL without pasting HTML, your browser attempts one direct request to that source website. To reduce repeated requests, it keeps a temporary, in-memory 15-second cooldown per recognized source (or generic host); this is discarded when the page closes. The source will receive normal connection information such as your IP address and browser headers under its own privacy policy. Meeple Import Doctor does not proxy, log, or receive that request.

What we collect

We do not collect personal data, pasted HTML, imported metadata, or usage events. The static hosting provider may retain short-lived security and access logs needed to operate the site; those logs are not used to profile you.

Offline cache

A service worker caches the application shell and original artwork so the interface can reopen offline. It does not cache third-party pages or pasted source. Remove the site’s stored data in your browser settings to clear it.

Questions

Open an issue in the public source repository. Do not include private catalog data or full page source in a public issue.
