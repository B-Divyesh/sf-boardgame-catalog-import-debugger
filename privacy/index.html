How your inspection data is handled

Meeple Import Doctor works without an account, analytics, cookies, advertising, or a server-side history.

What stays on your device

Your browser stores up to five recent checks in local storage. Each check stores the URL, source name, diagnosis, extracted title, and inspection time.

Pasted page HTML stays in memory only while the page is open. It is not saved in recent checks.

You can clear recent checks from home and restore them for seven seconds.

Requests to source websites

When you inspect a URL without pasted HTML, your browser sends one request to that website. A 15-second cooldown per source reduces repeated requests.

The cooldown stays in memory and disappears when the page closes. The source receives your IP address and browser headers under its privacy policy.

Meeple Import Doctor does not proxy, log, or receive that request.

What we collect

We do not collect personal data, pasted HTML, imported details, or usage events. The hosting provider may keep short-lived security and access logs.

Those logs operate and protect the site. They are not used to profile you.

Offline cache

A service worker caches this interface and its artwork so it can reopen offline. It does not cache source pages or pasted HTML.

Remove this site’s data in browser settings to clear the cache and recent checks.

Questions

Open an issue in the public source repository ↗. Do not include private catalog data or full page source.
