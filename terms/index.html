Use the tool with care.

Meeple Import Doctor is free, open-source diagnostic software. It reports what a browser request or pasted document contains; it does not guarantee that another catalog importer will behave the same way.

Responsible use

Inspect only public item pages you are permitted to access. Respect each source’s robots.txt, terms, copyright, and rate limits. The inspector permits one direct request per recognized source (or generic host) every 15 seconds in a browser session. This local safeguard is not a robots.txt verifier and does not grant permission to access a source. Do not use the tool to bypass authentication, anti-bot measures, regional controls, or other access restrictions.

One item at a time

The tool is intended for individual diagnosis, not bulk scraping or redistribution of marketplace data. Source attribution in exported JSON must be retained.

Your responsibility

Review normalized data before importing it. Publisher markup can be incomplete, inaccurate, or change without notice. You are responsible for backups and for changes made to your self-hosted catalog or scraper.
